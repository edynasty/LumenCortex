# Cognitive routing benchmarks

This directory contains the labeled cognitive-routing fixture and captured external-model calibration artifacts.

## Deterministic baseline

The canonical fixture is `cognitive-routing.json`. It exercises Category, Think activation, reasoning effort, and retrieval direction through the production deterministic Router.

```bash
lcx cognition benchmark
lcx cognition benchmark --strict
lcx cognition benchmark --strict --json
```

## External-model calibration

Generate the same unlabeled routing contract used by external model runners:

```bash
lcx cognition benchmark --prompt > /tmp/lcx-routing-prompt.txt
```

A subset can be emitted with:

```bash
lcx cognition benchmark --prompt --ids quick-readme-typo,deep-concurrency-root-cause
```

Score model predictions with the exact same fixture:

```bash
lcx cognition benchmark \
  --predictions benchmarks/predictions/deepseek-v4.1-flash-2026-09-26.jsonl \
  --strict --json
```

## Captured DeepSeek V4.1 Flash calibration

`predictions/deepseek-v4.1-flash-2026-09-26.jsonl` is a captured local OMP calibration artifact produced on 2026-09-26 with:

- model: `local/deepseek-v4.1-flash`
- OMP thinking: `low`
- prompt: generated by `buildCognitiveRoutingPredictionPrompt()`
- execution: two 6-case batches to stay within the local runner time budget
- score against the current 12-case fixture: 12/12

This is calibration evidence for the routing contract. It is not a live Jev/Laya endpoint test and is not evidence that a DeepSeek model completed the full autonomous coding workflow.
