# Context 与 Evidence

Context 是当前任务提供给模型的信息集合；Evidence 是支持某个判断的来源和检查记录。两者相关，但不能混为一谈。

## Context

Context 可以包含：

- 当前任务目标和限制；
- 相关 Session 历史；
- Notes 和知识片段；
- Cognitive Graph 中相关节点；
- 已有经验候选；
- 尚未解决的问题和冲突。

Context 必须有大小上限。系统应优先选择与当前任务有关的信息，而不是把全部历史塞给模型。

## Evidence

Evidence 至少需要说明：

- 它支持哪个判断；
- 来源在哪里；
- 由谁或什么过程产生；
- 适用哪个项目、环境和时间；
- 是否经过真实检查；
- 是否已被撤销、过期或出现冲突。

模型生成的文字可以作为待验证的主张，不能自动成为独立 Evidence。

## 使用规则

读取知识时，需要结合当前 Reader、Scope、Time 和来源状态判断是否仍然适用。

如果证据不足，应该保留 Unknown；如果证据冲突，应明确呈现冲突；不能仅因检索到了某条内容就把它当成事实。

## 限制

Context 被选中不代表内容正确；Evidence 存在也不代表它足以证明所有相关结论。每项检查只能支持它实际检查的范围。
