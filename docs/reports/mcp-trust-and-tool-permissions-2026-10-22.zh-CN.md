# MCP 项目信任和工具权限（中文摘要）

英文原文：[MCP trust and tool permissions](mcp-trust-and-tool-permissions-2026-10-22.md)

## 目标

防止项目仓库通过自己的 MCP 配置提高工具权限，或在工作区未获信任时启动外部服务。

## 主要规则

- 全局 MCP 配置由用户管理。
- 项目 MCP 配置只有在工作区被全局信任后才生效。
- 信任在 Run 启动和工具调用时重新检查。
- 工具权限按 read、write、exec 分类。
- Server 声明和可信 Host 覆盖共同决定有效权限。
- 凭据通过环境变量引用，不能明文持久化。
- 撤销信任后，项目 MCP 工具不再提供给新的调用。

## 实现原理

Core 在加载项目配置和列出/调用工具时检查工作区身份与信任状态。MCP 工具仍经过统一工具权限门禁，项目文件不能给自己授予更高权限。
