# RUNTIME-004：定时器和计划任务（中文摘要）

英文原文：[RUNTIME-004 schedules](runtime-004-schedules-2026-11-01.md)

## 目标
为 Runtime 提供可管理的定时触发和 Cron 计划任务，不引入隐藏的无限后台执行循环。

## 主要设计
- 定时任务由 Engine/Host 明确创建和管理。
- 触发记录必须持久化，避免进程重启后丢失已提交状态。
- 对错过的触发时间有明确处理规则。
- Cron 表达式和下一次触发时间由统一调度逻辑计算。
- 任务执行仍经过现有权限、并发和 Run 生命周期。

## 实现原理
调度器负责计算何时触发；RunSupervisor 负责是否允许启动；Session/Job 记录负责结果和恢复。定时触发不能绕过普通 Agent 权限。
