# M2.3 模型 Runtime 切换（中文摘要）

英文原文：[M2.3 model runtime cutover](M2.3-model-runtime-cutover.md)

## 目标
将模型调用统一到 Go Runtime，明确 Provider、配置、协议、持久化和故障处理。

## 主要内容
报告记录架构决策、公开 API 变化、SQLite Migration、旧组件保留/移除、安全问题、实际测试、提交范围和平台限制。

## 实现原则
Provider 负责协议适配，Runtime 负责调用生命周期；配置与凭据有明确来源；流式响应确认结束后才执行工具；旧数据和配置通过可验证 Migration 迁移。

## 边界
报告中的测试和提交只代表当时的候选版本，不能直接代替当前 main 状态。
