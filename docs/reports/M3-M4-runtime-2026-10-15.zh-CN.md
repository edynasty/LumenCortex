# M3/M4 Runtime 实施：Task State、上下文窗口和 Evaluator（中文摘要）

英文原文：[M3-M4 runtime](M3-M4-runtime-2026-10-15.md)

## 实施范围
报告覆盖 Task State、上下文窗口裁剪、Resolution 和执行完成条件等阶段。

## 主要设计
- Task State 保存目标、引用、工作状态和结果。
- 上下文窗口按完整消息/工具组裁剪，不能破坏工具调用配对。
- Resolution 与模型回答分离。
- 任务完成依赖确定性状态和必要检查。
- Resume 必须保留 Session 历史和任务状态。

## 验证边界
报告记录各阶段实现决定和测试证据；后续 Delivery Contract 与执行任务语义以更新后的 ADR 和组件文档为准。
