## 2. Decisions

| # | Decision | Reason |
|---|---|---|
| D1 | Two semantics, one rule each. Exits whose result reaches a **model** (`list_subagents`, `wait_subagent`, the `OriginTaskResult` delivery; `read_thread`/`recall` since T2-S1/T3-S1) **filter**: a withdrawn session's content is not returned and no edge cites it. Exits read by the **host** for the owner's view of the transcript (`MessagePage`, `RecentMessages`) **mark**: every row is returned, `Message.Withheld` says no run sends it again. | DATA §5 blocks the next *use*. The owner's transcript is not a use; privacy deletion (T3-S4) is what removes bodies. Marking keeps counts and paging identical to the transcript. |
| D2 | `SubagentTree` is shared by the host and the `list_subagents` tool, so it filters for both: a withdrawn child's node has `withdrawn: true`, identity and status, no goal, no final. | One builder (`RunSupervisor.subagentNode`) for tree, spawn and wait; no second code path. |
| D3 | "Withdrawn" is the source read (`Store.SessionWithdrawn` = any fence on the session, projected or not), the same predicate `read_thread` uses (`ContextRow.Fenced`). | A projected reader may continue itself (T3-S2) but stays uncitable. |
| D4 | A withdrawn child's task result carries `taskId`, `sessionId`, `agent`, `status`, `withdrawn: true` only (no objective, error, final, units, checks, handoff). Its delivery advances the cursor (delivered once) and its edge is dropped from the Start's Task State write. | Resolves the T3-S1 OPEN item: before, the delivery edge cited the fenced child and every Start of the parent was refused. The handoff lists files the child produced; the objective is the child's goal row. |
| D5 | Host marks come from `Store.Projection`: all rows when the thread cannot be projected (revoked source, exposed, …), else the rows the projection withholds. A session no fence names costs one indexed read per page. | Same answer the next Start uses; no second derivation. |
| D6 | `SessionCheckpoints` is unchanged: since T1-S6 checkpoint payloads hold ids, status and agent only. Verified, not filtered. | Nothing to remove. |
| D7 | The Auto judge (`runtime/auto.go`) needs no change: it reads only user rows without origin and assistant rows; withheld rows are tool and task-result rows, and an assistant row produced from a window holding withheld content isolates the thread (T3-S2 `exposed`). | Checked against `classifyTurn`. |

## 7. OPEN items and known limits

- **Known limit:** `SessionInfo` (`Engine.Session`, `ListSessions`) still returns a revoked session's goal and final
  to the host, unmarked. Not in the plan's exit list; the owner's own view.
- **Known limit:** in-memory events published before or while a revocation commits (`subagent.stopped` carries the
  child's final) are not recalled; events are not a persisted exit.
- **Race (fail-closed):** a fence landing between the delivery read and the Start commit refuses that Start; the
  next Start delivers the child withdrawn.
- **Cost:** per host page, one `Projection` read (one indexed read when unfenced); per tree node and per delivered
  child, one indexed fence read.
