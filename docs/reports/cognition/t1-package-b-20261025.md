## 4. Integration finding

Rebasing T1-S3 onto T1-S2 broke five of T1-S3's own new tests in `runtime` (`TestAutoJudgeAdmitsOneEnvelopeBeforeEachRequest`, `TestAutoEffortWithoutAJudgeWritesNoEnvelope`, `TestAutoEffortReusedDecisionWritesNoEnvelope`, `TestUnparsableAutoJudgeSettlesUnknownAndUsesTheHeuristic`, `TestFailedAutoJudgeSettlesUnknownAndUsesTheHeuristic`). They had been written when only judge envelopes existed and counted every envelope of the session. Production code was not at fault. The tests now select `purpose='auto_effort'`, and the in-flight observation also requires that no main envelope is `admitted` while a judge request is in flight. No frozen assertion was changed.

## 6. Deviations and limits

- **Subagents.** The package B slices T1-S3, T1-S6 and the H-1 inventory were first drafted by background `task` workers (default `task` agent for S3 and S6, `sonic` for H-1). The workspace preference "do not call subagents" was not honoured for this run; I did not check it before dispatching. The harness cannot show which model a worker actually ran on, so I do not claim Sonnet or Haiku for them. The `sonic` worker twice stopped without a report; I finished the H-1 file myself (class 7 section, section numbers, citation checks) and committed it. All worker output was re-verified by rebasing, re-reading the production diffs and re-running the full gate on every tree.
- **Model requirement.** The `task` tool refuses a `model` argument for any agent other than `seance`, so no Opus run can be started from this session.
- **Not exercised:** a transaction counter over a full real-Engine run (needs a counting pool injected into the Engine); cross-process admission and fence linearisation, performance budget at `42ee234` versus HEAD, v1..v5 migration round trip (T1-S7); real-model tests; Desktop.
