`provider/openai`: `ErrNoEndpoint`, `FromModel(config.ResolvedModel, Options)`, request and idle timeouts, Retry-After cap (`maxInAdapterRetryAfter = 5 s`).

## 4. SQLite migration and compatibility

- `internal/migrate/sql/0002_model_ref.sql` and `down/0002_model_ref.down.sql` are byte-identical to the verified contract in `../LumenCortex-architecture-audit/design/verify/sql/` (checked with `diff`).
- `sessions.model_ref TEXT` with a CHECK (`provider/model`, one slash, both sides non-empty); no backfill: legacy rows keep NULL because `provider`/`model` hold the provider id and upstream model id, not the catalog reference. The first Start of such a session writes the resolved ref (rule `model.default`) in the same transaction as Input and `running`.
- Downgrade to version 1 drops the column; downgrade to version 0 is refused before any backup; concurrent Opens converge on the shipped schema; a failing 0002 rolls back and a later Open recovers (`internal/migrate/model_ref_test.go`).
- A binary that predates 0002 refuses the database as newer (existing M2.1 behaviour). A Desktop that opens a version-1 database migrates it to 2 with a backup.

## 6. Security and correctness findings

- **F1 (P0, fixed in `9c1de52`)**: `openai.New` fell back to `https://api.openai.com/v1`, so a provider with only an `apiKey` sent the key and transcript to api.openai.com. Now refused at construction; the CLI test runs the real entry point with every proxy variable pointed at a recording server and sees zero requests, and no session is created.
- **Cancellation vs timeout (F2)**: only the run context decides cancellation (`agent.Classify`). An adapter error that claims `cancelled` while the run context is alive, or a bare `context.Canceled`, is availability; an idle or request timeout is its own error and never ends the run as cancelled.
- **No credential redirection by failover**: auth and bad-request errors end the run and never reach another candidate (`TestAuthAndBadRequestDoNotFailOver`: the failover providers record zero calls).
- **Hidden reasoning**: a streaming provider that returns `reasoning_content`, `reasoning` and `reasoning_details` leaves no trace in the SQLite file (db, `-wal`, `-shm`), the event stream or the next request (`TestHiddenReasoningIsNeverPersisted`). Decision log entries hold only observable inputs.
- **Rejected starts are atomic**: unknown/malformed model, invalid effort, no tool calling, unset key variable, missing endpoint, unknown failover model, failover model with unset key, factory error — each leaves the session row and transcript identical and calls no provider.
- **Residual**: an in-adapter idle timeout is retried, so a hung provider can take up to about 3 × idle timeout (default 3 × 120 s) before failover, as the handoff predicted; not tuned.

## 10. Outstanding risks and M2.4 integration contract

Findings still open after owner approval ([ADR-0004](../adr/0004-m23-model-runtime-decisions.md)): **P2** first Desktop open of a version-1 database migrates it with a backup and can wait up to `LockWait` (30 s) or return `ErrDatabaseInUse` while a CLI process holds the workspace — the UI must handle both; **P2** idle timeout × retries can delay failover on a hung provider (§6); **P3** `effort.escalation` silently ignored; **P3** `npm test` shell-streaming timing failure; **P3** `docs/cognitive-control-plane.md` and the Node sections of `README.md` still describe the Node reference runtime's Decision Layer and Category chains (not Core Go, not rewritten here).

M2.4 contract (Desktop pins this commit with `go get`, touching only `go.mod`/`go.sum`):
1. Open the engine with `runtime.Options{Workspace, ProviderFactory}`; pass a factory only to inject clients, otherwise the default builds `openai.FromModel`.
2. Start a run with `Supervisor.Start(ctx, id, runtime.AgentOptions{ModelRef, Effort, ...})`; leave `ModelRef` empty to continue on the pinned model. Read `SessionInfo.ModelRef` for the pin; it is empty for sessions that never started.
3. A rejected Start returns before any write: `ErrUnknownModel`, `ErrModelWithoutToolCalling`, `ErrInvalidEffort`, a key-variable error naming the variable, or `openai.ErrNoEndpoint`. The session is unchanged and a different model can be offered.
4. Failover never changes `ModelRef`; the answering model is in each step record (`agent_steps.json`: `modelRef`, `decisions`) and in the `llm.request`/`llm.complete`/`provider.failover` events (`modelRef`, `nextModelRef`, `class`).
5. Terminal causes: `failed` with kind `provider:auth`, `provider:bad_request`, `provider:capacity`, `window_overflow`, `config`; `interrupted` with `cancelled`, `provider:availability`, `max_steps`.
6. The model picker comes from `config.Load(workspace).Catalog()`; `config.Provider(id)` gives provider settings without credentials.
