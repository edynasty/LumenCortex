# Phase 0：项目输入、工作区信任和有效 Prompt（中文摘要）

英文原文：[Phase 0 trust](phase0-trust-2026-10-22.md)

## 目标
明确全局配置、项目配置、指令文件和 Skills 的来源及信任规则，避免不可信仓库影响用户权限。

## 主要内容
- 全局输入与项目输入分开。
- 项目输入只有在工作区可信时才生效。
- 有效 Prompt 按明确顺序组装，并保留来源。
- 工具权限不能由 Prompt 文本提升。
- 指令文件和项目配置有大小、路径和信任边界。

## 实现原理
Host 先确定 Engine 工作区身份和信任状态，再读取允许的项目输入。Core 负责合并、校验和记录来源；项目文件不能授予自己信任。
