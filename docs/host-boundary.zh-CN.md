# Host 边界

Host 是运行 LumenCortex 的宿主程序。它负责提供模型、工具、权限、文件系统、进程和外部服务等真实能力。

Core 不应假定模型可以直接访问宿主资源；所有外部能力都必须通过 Host 明确提供的接口。

## Host 负责什么

- 提供模型请求和响应。
- 决定工作区和项目身份。
- 配置工具权限和人工批准。
- 启动受管理的 Shell、Eval、DAP 和 MCP 进程。
- 执行获准的检查并返回真实结果。
- 提供取消、超时和资源限制。
- 管理 Desktop 与 Core 之间的交互。

## Core 负责什么

- 验证请求身份和当前 Session/Run。
- 检查权限和工作区范围。
- 约束工具参数和状态变化。
- 记录来源、执行结果和生命周期事件。
- 执行隐私隔离、事务和恢复规则。
- 拒绝没有明确授权的操作。

## 重要边界

模型输出不是 Host 证据。模型不能自己声明文件已经写入、检查已经通过或任务已经完成。

Host 也不能绕过 Core 的权限、来源和状态规则，直接写入权威认知状态。

具体 API 和配置以当前 Go 接口及对应组件文档为准。
