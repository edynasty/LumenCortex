# Plugins 和 MCP 模板

MCP 用于把外部工具或服务接入 LumenCortex。Plugin/模板提供配置样例和能力说明，不代表 Core 内置了对应的外部服务。

## MCP 配置

MCP Server 可以通过 stdio 或支持的 HTTP 传输接入。配置包含启动命令、参数、传输方式、环境变量引用、工具列表、超时、并发和结果大小限制。

凭据只通过环境变量名称引用，在启动或请求时读取，不把密钥明文写入配置和数据库。

## 工作区配置与信任

全局配置由用户管理。项目目录中的 MCP 配置只有在该工作区被明确加入信任列表后才生效。

撤销信任后，项目 Server 的工具不再提供给新的调用。项目配置不能通过声明只读来覆盖 Server 实际没有声明的权限。

## 工具权限

每个工具都有有效权限：

- read：读取。
- write：修改数据。
- exec：执行命令或产生执行副作用。

有效权限来自 Server 声明和可信 Host 覆盖配置。Agent 的当前策略仍然可以进一步限制权限。

## 生命周期

Engine 打开时不会自动启动所有 MCP Server。需要读取工具目录或调用工具时才启动；空闲、显式停止或 Engine 关闭时按规则停止。

启动失败、崩溃或调用超时会作为工具错误返回，不应伪装成功。

## 模板管理

官方模板是配置数据，可以通过 CLI 查看和应用。应用模板不会自动授予超出当前策略的权限。

MCP 接入不等于浏览器、电脑操作或任意外部系统已经成为 Core 内置能力。
