# ADR-0003：分离认知判断、任务推理和知识治理

## 背景
若同一个模型同时决定任务类别、推理强度、执行路线和知识修改，就会把建议、执行权限和持久化治理混在一起。

## 决策
- **Cognitive Kernel / Router**：确定性框架，掌握最终路由、预算、权限和 Think 决定。
- **Decision Layer**：提供有限判断信号，可由算法或可插拔 Provider 提供。
- **Category 模型链**：用户为不同任务类别配置有序生成模型候选。
- **Think**：由框架决定是否深入推理及其模型和强度。
- **Graph Governor**：负责长期知识图维护。

## 实现原理
Decision Provider 只回答结构化问题，不执行任务、不调用工具、不直接修改知识图。Framework 综合判断信号、运行状态、预算和 Workflow 约束后作决定。模型提出的知识修改计划必须经过验证和授权。

## 边界
这是历史目标设计。当前 Go main 的实际能力以 Go 源码和测试为准；只读 Governor 不等于已经具备 Graph Apply。
