# ADR-0021：能力目录和 MCP 按需生命周期

## 目标
统一展示 Agent 可用的内置工具、LSP 和 MCP 能力，避免 Engine 启动时就启动所有外部服务。

## 决策
- `Engine.Capabilities` 是当前 Run 可用能力的统一视图。
- 能力说明包含来源、权限、可用状态、执行约束和配置要求。
- MCP Server 按需启动，空闲后停止。
- 工具权限由 Server 声明和可信 Host 覆盖配置共同决定。
- 项目 MCP 配置受工作区信任约束。
- 凭据只使用环境变量引用，不保存明文。
- 查询能力目录不应意外启动外部进程。
- Server 崩溃、超时和资源限制必须可观察。

## 实现原理
Capability Registry 描述工具，不替代权限系统。MCP Manager 管理按需启动、并发、超时、空闲关闭和错误状态；调用仍经过统一权限门禁。
