# ADR-0013：项目输入和工作区信任

## 决策
项目仓库中的配置、指令和 Skills 默认不可信。用户必须在全局配置中明确授予工作区信任，并在每次 Run 和工具调用时重新检查。

- 工作区路径规范化后与全局可信列表精确比较。
- 不从父目录继承信任，也不允许项目文件自行授予信任。
- 全局配置不受项目工作区信任门禁限制。
- 项目配置、指令和 Skills 从 Engine 打开的工作区读取，不从 Session Worktree 读取。
- 项目指令文件有大小上限；过长时截断并警告。
- 不可信项目不能通过 MCP 配置提高工具权限。

## 实现原理
每次启动 Run 时重新加载全局配置；MCP 工具列出和调用时再次检查。撤销信任后，项目工具不再提供给新调用。这样可防止恶意仓库通过自己的配置文件提升权限。
