# ADR-0015：Skill 发现和目录加载

## 目标
让 Agent 能找到可用 Skills，但不要每次模型请求都发送全部 Skill 正文。

## 决策
- Core 维护 Skill Catalog 和来源信息。
- 首先提供有限的名称、说明和调用方式。
- 任务需要时再读取具体 Skill 内容。
- 项目 Skills 受工作区信任规则约束。
- 来源不可信或格式无效时拒绝加载。
- Skill 内容是指导资料，不自动授予工具权限。

## 实现原理
把目录发现和正文加载分开：Catalog 列出能力，按需读取提供细节。工具权限仍由注册信息和 Host 策略决定，不能因为 Skill 文本要求执行操作就自动放行。
