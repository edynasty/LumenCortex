# ADR-0018：请求来源和隔离 Fence

## 目标
防止 Session、Run、Worker 或来源被撤销后，旧请求继续读取或修改已不再授权的数据。

## 决策
- 请求绑定明确的 Session、Run、调用者和来源。
- 关键操作在执行前和提交时检查授权状态。
- 来源撤销、Session 删除和隐私清理必须影响后续读取。
- 旧请求不能仅凭启动时获得的权限继续写入。
- 跨 Session 数据必须保留来源。
- 并发状态变化使用版本、Fence 或 CAS 保护。

## 实现原理
请求携带来源身份和版本。Core 在准入、执行和提交边界重新检查；来源已撤销或版本过期时拒绝提交。读取、回放、事件和派生内容也必须执行相同检查。
