# ADR-0000：架构决策记录模板

> 本文件是中文填写说明，正式决策以同目录英文原文为准。

## 基本信息
- 状态：Proposed / Accepted / Superseded / Rejected
- 日期、负责人、取代的决策、被哪项决策取代。

## 背景
说明遇到什么问题、当前系统有什么限制，以及为什么必须做决定。只写与决策有关的事实。

## 决策
明确最终选择、适用范围和不能破坏的规则。

## 考虑过的方案
列出可行替代方案及未选择的原因。

## 影响
说明收益、代价、安全和信任影响、数据兼容性及维护成本。

## 验证计划
列出能证明决策实现正确的具体测试、运行场景和平台。

## 文档影响
列出需要同步更新的 README、组件说明、运维文档和用户文档。
