# ADR-0019：执行 Runtime——超时、Deadline、后台任务和诊断

## 目标
统一 Agent 工具和后台命令的生命周期，让超时、取消、恢复和资源归属清楚。

## 决策
- 工具调用有独立超时，Run 可以有整体 Deadline。
- 取消传递给受管理的子进程和子任务。
- 后台 Job 由持久化记录管理，不能只靠内存 Goroutine。
- Job 状态使用原子状态变更，重启后能识别排队、运行和结果未知的任务。
- Run 结束时清理自己拥有的 Job。
- 完成门禁不能忽略仍在运行的自有 Job。
- 定时任务由 Host/Runtime 明确管理。
- 诊断信息有大小和保留限制，敏感内容不能写入日志。

## 实现原理
使用受管理进程启动器、持久化 Job 表、状态 CAS、取消信号和有限清理时间。进程死亡后无法确认结果时标记 `outcome_unknown`，不能假装成功。
