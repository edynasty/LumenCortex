# ADR-0011：导入 OMP Session

## 目标
把 OMP 历史会话导入为 LC 原生 Session，优先保证历史完整、重复导入安全和数据不被破坏。

## 决策
- 导入后使用 Core 原生 Session 存储和读取接口。
- 保留来源标识，区分导入会话和原生会话。
- 重复导入必须幂等，不能重复创建同一批消息。
- 不把无法解释的 OMP 内部状态伪装成 LC 原生状态。
- 对附件、压缩摘要和不支持的记录类型明确标记边界。
- 导入失败不能破坏原始数据，也不能留下无法识别的半成品。

## 实现原理
解析源格式，将消息、工具调用、结果和附件引用映射到 LC 数据模型；通过来源 ID 和内容身份识别重复导入。具体字段映射见英文原文。
