# ADR-0006：任务上下文、结果判定和对话式执行

## 背景
一轮回答结束不代表整个任务完成。任务目标、执行过程、验证结果和最终状态必须分开。

## 决策
- Task State 保存 Brief 和引用，避免上下文裁剪后丢失任务目标。
- Resolution 表示任务结果，必须由事实和检查结果支持，不能只依赖模型文字。
- 当前对话轮可以结束，但未完成的 Work Unit、必需检查或人工 Gate 会阻止整个任务完成。
- 子任务使用独立 Session 和状态；父任务根据真实执行和验证结果判断依赖。

## 交付义务增补
Host 可以明确指定文件、分支和提交要求。Core 在 Agent 执行结束后独立检查交付。执行状态和交付验证状态分开记录。

## 实现原理
Task State 持久化任务目标、引用、工作单元和结果；Completion Gate 读取真实状态，不接受模型自行声明完成。详细字段和状态机见英文原文。
