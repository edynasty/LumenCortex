# ADR-0016：外部状态存储和工作区绑定

## 目标
把 LC 数据库、配置和运行状态放在项目源码目录之外，同时确保它们绑定到正确工作区。

## 决策
- Session 数据库和 Runtime 状态使用明确的外部状态目录。
- Engine 打开时绑定规范化后的工作区身份。
- 不允许通过符号链接或路径别名访问另一个工作区的状态。
- 文件工具只能访问授权工作区。
- Worktree 是执行工作区，不改变 Engine 的项目身份和信任来源。
- 删除 Session、Worktree 或状态目录时遵守统一所有权和清理规则。

## 实现原理
Engine 打开时解析真实工作区路径并记录身份。文件操作从真实根目录逐段检查路径，防止 `..` 和符号链接逃逸。状态目录与项目文件分离，避免 Agent 修改项目时误删数据库。
