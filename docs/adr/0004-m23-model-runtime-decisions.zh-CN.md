# ADR-0004：M2.3 模型 Runtime 切换决策

## 背景
M2.3 统一模型请求、Provider 协议、配置、重试、推理格式和兼容边界。

## 决策原则
- Provider 协议适配与 Agent Loop 分离。
- 模型、Provider、凭据和推理格式有明确配置来源。
- 重试只针对可恢复的可用性故障，不能重放非幂等工具。
- 流式响应必须确认完整结束后才能执行工具调用。
- 旧配置迁移必须可验证，不能静默丢弃用户设置。
- 不同模型的能力差异通过配置和适配层表达。

## 增补
2026-10-22 接受 PROVIDER-001：推理格式按模型声明，不依赖全局猜测。

D1–D6 原始条款、API 和验证结果见 [英文原文](0004-m23-model-runtime-decisions.md)。
