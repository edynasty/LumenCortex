# Go Provider 配置与重试

Provider 负责把 Core 的模型请求发送到指定模型服务，并把响应转换为统一格式。

## 配置

Core 支持官方 Provider 和 OpenAI 兼容接口。具体 Provider、模型名、Base URL 和 API Key 由 Host 配置。

密钥应通过环境变量或安全配置提供，不应写入仓库或日志。

## 重试原则

重试只用于明确可恢复的可用性错误，例如连接中断、限流或暂时性服务错误。

以下情况不能盲目重试：

- 请求参数错误；
- 权限拒绝；
- 模型明确拒绝；
- 内容过滤；
- 已经执行过的非幂等工具调用。

Provider 请求重试发生在同一个执行 Step 内，不额外增加 Agent Step。重试等待必须响应取消和 Deadline。

## 流式响应

只有收到 Provider 明确的结束标志，才认为响应完整。流中途断开或包含错误事件时，不能执行尚未完整接收的工具调用。

如果模型响应因输出长度限制而截断，需要按实际完成状态处理，不能把不完整文本当作最终答案。

## 用量与边界

记录 Token、请求次数和可用的成本信息。不同 Provider 的用量字段可能不同，缺失数据不能伪造为精确值。

Provider 成功返回不代表模型结论正确；语义检查和工具验证仍由其他机制负责。
