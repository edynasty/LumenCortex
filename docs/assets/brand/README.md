# Brand assets

- `lumencortex-app-icon.png` is copied byte-for-byte from `LumenCortex-Desktop/build/appicon.png` (1024 × 1024 RGBA). This is the same glass-master app icon generated from Desktop's `build/appicon.svg` and installed into the macOS app bundle via `build/darwin/iconfile.icns`.
- The README uses this canonical Desktop app icon. Do not substitute the flat A1 running indicator (`a1-flat.svg`) or the small-size icon master (`appicon-small.svg`) for the full app icon.

When the Desktop app icon changes, refresh this copy from the Desktop repository and verify the SHA-256 hashes match.
