# Runtime 生命周期 Hook

Hook 允许 Host 在 Agent 生命周期的指定位置运行受信任的检查或外部命令。Core 使用同一个生命周期分发器，不另建注册中心或后台发现服务。

## 可挂接的位置

包括：

- Agent Run 开始和结束；
- 模型请求前后；
- 工具调用前后及工具失败；
- 子 Agent 启动和结束；
- Eval 执行前后；
- DAP 启动和停止；
- Workflow 状态变化前后；
- 验证前后；
- 交付检查前后；
- 上下文压缩前后。

具体事件以当前 Go 接口为准。

## Hook 可以做什么

支持继续、拒绝，以及在明确允许的字段范围内修改参数。只有特定的非安全 BeforeToolCall Hook 可以在 Host 提供校验器时修改工具参数；修改后必须重新验证。

Hook 不能修改 Session/Run 身份、工具身份、权限、Workflow 事实或验证结果。

## 安全要求

安全 Hook 失败时必须拒绝操作，不能把拒绝转换为允许。普通观察 Hook 的错误不能改变已经完成的操作。

每个 Hook 有独立超时，嵌套调用有深度限制。可信 Go Hook 必须遵守 Context；进程外 Hook 使用受管理的沙箱命令。

外部命令由 Host 明确指定程序、参数、读取路径和沙箱。不会继承宿主环境、网络权限或 Engine 控制句柄。

macOS 有实际沙箱运行证据；Linux 和 Windows 必须按各自平台的隔离能力判断，不能从 macOS 结果推断通过。
